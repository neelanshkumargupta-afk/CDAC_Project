# CDAC_Project
A CAN-based Smart In-Cabin Safety System with IOT Telemetry.

Description :- A CAN-based Smart In-Cabin Safety System with IOT Telemetry monitors cabin safety using sensors and CAN bus communication and STM32 Discovery Board. It detects unsafe 
conditions such as occupant presence and abnormal temperature and sends real-time alert to the car owner, through IOT for remote monitoring and enhanced vehicle safety.
